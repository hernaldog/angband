Angband es un juego de aventuras y mazmorras con una interfaz gráfica que utiliza caracteres de texto para
representar las paredes y los suelos de una mazmorra y sus habitantes, al estilo de
juegos como NetHack y Rogue. Si necesitas ayuda durante el juego, pulsa `?`.

- **Instalación de Angband:** Consulta el [Sitio web oficial](https://angband.github.io/angband/) o [compílalo tú mismo](https://angband.readthedocs.io/en/latest/hacking/compiling.html).
- **Cómo jugar:** [Manual de Angband](https://angband.readthedocs.io/en/latest/)
- **Ayuda:** [Foros de Angband](https://angband.live/forums/)
