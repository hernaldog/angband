# Hechizos de monstruos
# Usado junto con list-mon-spells.h.

# name - establece el nombre del hechizo; debe coincidir con el primer argumento
#        (distinto de NONE o MAX) de una de las macros RSF() en list-mon-spells.h
# msgt - establece el tipo de mensaje a usar para los mensajes message-vis,
#        message-invis y message-miss del hechizo actual; el tipo debe coincidir
#        (sin distinción de mayúsculas/minúsculas) con el primer argumento de una
#        de las macros MSG() en list-message.h o ser un entero sin signo menor que
#        MSG_MAX que sea el índice del tipo de mensaje a usar dentro de list-message.h;
#        para la interfaz de texto, el tipo de mensaje afecta al color del mensaje
#        (configurado globalmente por lib/customize/message.prf; también configurable
#        mediante preferencias en los archivos del usuario) y el sonido reproducido
#        cuando se muestra el mensaje (configurado globalmente por
#        lib/customize/sound.prf; también configurable mediante preferencias en los
#        archivos del usuario)
# hit - establece la probabilidad base de acertar (100 = siempre, 0 = nunca) para el
#       hechizo actual; la probabilidad base se ajustará por el nivel del monstruo y
#       por los efectos temporales que afectan al monstruo
# effect - añade un efecto al hechizo actual; puede especificarse múltiples veces
#          para aplicar múltiples efectos del mismo hechizo; cuando se lanza el
#          hechizo, los efectos se aplican en el orden en que se dan
#          parámetro uno: es el nombre del efecto incorporado a usar; el nombre
#              debe coincidir con el primer argumento de una de las macros EFFECT()
#              en list-effects.h
#          parámetro dos: es el subtipo del efecto dado a usar; puede omitirse
#              (junto con el tercer y cuarto parámetro) si no es necesario para el
#              efecto
#          parámetro tres: es el valor a usar para el parámetro de radio del efecto;
#              debe ser un entero; puede omitirse (junto con el cuarto parámetro)
#              si no es necesario para el efecto
#          parámetro cuatro: es el valor a usar para el parámetro "other" del efecto;
#              debe ser un entero; puede omitirse si no es necesario para el efecto
# effect-yx establece los parámetros y y x para el efecto anterior en el hechizo
#           actual; puede omitirse si el efecto no usa esos parámetros
#           parámetro uno: es el valor para el parámetro y del efecto
#           parámetro dos: es el valor para el parámetro x del efecto
# dice - establece la cadena de dados de daño para el efecto anterior en el hechizo
#        actual; puede omitirse si el efecto no la necesita
# expr - define una expresión para los dados vinculados al efecto anterior en el
#        hechizo actual; se ignorará si el efecto anterior en el hechizo actual no
#        ha tenido una cadena de dados especificada
#        parámetro uno: es el nombre de la variable en la cadena de dados a
#            sustituir con el valor de la expresión; los nombres de las variables
#            deben ser totalmente en mayúsculas y una referencia a una variable en
#            una cadena de dados comienza con $; si la cadena de dados no contiene
#            una referencia a la variable dada, el análisis de los archivos de
#            datos del juego se detendrá con un error
#        parámetro dos: establece el nombre del valor base a modificar con las
#            operaciones en el tercer parámetro; el nombre puede ser uno de los
#            enumerados a continuación; si no coincide con ninguno de la lista,
#            el valor base será cero
#              SPELL_POWER - el poder de hechizo del monstruo
#              PLAYER_LEVEL - el nivel del jugador
#              DUNGEON_LEVEL - el nivel de la mazmorra
#              MAX_SIGHT - el alcance máximo de visión, en casillas
#              WEAPON_DAMAGE - una tirada aleatoria para el daño base (solo se
#                  incluyen los dados del arma y el modificador de daño; no se
#                  utilizan modificadores de daño del jugador o equipo aparte del
#                  arma) del arma equipada del jugador; si el jugador no tiene
#                  arma equipada, el valor de esto es cero
#              PLAYER_HP - el número actual de puntos de vida del jugador
#              MONSTER_PERCENT_HP_GONE - ((puntos de vida máximos del monstruo
#                  objetivo del jugador - puntos de vida actuales del monstruo
#                  objetivo del jugador) * 100) / puntos de vida máximos del
#                  monstruo objetivo del jugador o 0 si el jugador no tiene
#                  actualmente un monstruo objetivo
#        parámetro tres: establece las operaciones a realizar sobre el valor base
#            para obtener el valor sustituido en la expresión de dados; por ejemplo,
#            "* 2 / 3" multiplicaría el valor base por 2 y luego dividiría ese
#            resultado por tres, descartando cualquier resto; los operadores que
#            están permitidos son '+' (suma), '-' (resta), '*'
#            (multiplicación), '/' (división entera; descarta el resto),
#            y 'n' o 'N' (niega el resultado anterior al operador);
#            las constantes enteras en las operaciones deben estar entre -32768 y
#            32767; los operadores y constantes enteras en las operaciones deben
#            estar separados por un solo espacio
# power-cutoff - establece un poder de hechizo de monstruo en el cual pasamos a un
#                nuevo conjunto de configuraciones de lore, lore-color-base,
#                lore-color-resist, lore-color-immune, message-save, message-vis,
#                message-invis y message-miss para el hechizo actual; para que
#                funcione correctamente, el corte especificado debe ser mayor que
#                cero y mayor que cualquier corte de poder especificado previamente
#                para el mismo hechizo; el poder de hechizo de un monstruo es, por
#                defecto, igual a su profundidad (es decir, el valor de la directiva
#                "depth:" para el monstruo en monster.txt) pero eso puede ser
#                anulado por una directiva "spell-power:" para el monstruo en
#                monster.txt
# lore - establece la descripción impresa en el recuerdo del monstruo después de
#        "Puede" para el hechizo actual, p.ej. "causar heridas críticas"; las
#        descripciones de múltiples líneas lore en el mismo hechizo sin una línea
#        power-cutoff intermedia se concatenarán
# lore-color-base - establece el color base para lore; puede ser un código de color
#                   de un solo carácter o el nombre completo (sin distinción de
#                   mayúsculas/minúsculas) del color
# lore-color-resist - establece el color para lore cuando el hechizo es resistido;
#                     puede ser un código de color de un solo carácter o el nombre
#                     completo (sin distinción de mayúsculas/minúsculas) del color
# lore-color-immune - establece el color para lore cuando el hechizo es resistido
#                     fuertemente; puede ser un código de color de un solo carácter
#                     o el nombre completo (sin distinción de mayúsculas/minúsculas
#                     del color)
# message-save - establece el mensaje mostrado si el jugador realiza una tirada de
#                salvación exitosa contra el hechizo; debe proporcionarse para
#                permitir al jugador una tirada de salvación contra el hechizo; los
#                mensajes de múltiples líneas message-save en el mismo hechizo sin
#                una línea power-cutoff intermedia se concatenarán
# message-vis - establece el mensaje impreso cuando el hechizo es lanzado por un
#               monstruo visible, p.ej. "{name} te señala, ¡recitando terriblemente!";
#               los mensajes de múltiples líneas message-vis en el mismo hechizo
#               sin una línea power-cutoff intermedia se concatenarán
# message-invis - establece el mensaje impreso cuando el hechizo es lanzado por un
#                 monstruo invisible, p.ej. "Algo profiere una terrible invocación!";
#                 los mensajes de múltiples líneas message-invis en el mismo
#                 hechizo sin una línea power-cutoff intermedia se concatenarán
# message-miss - establece el mensaje impreso cuando un monstruo conocido/visible
#                falla el ataque de hechizo contra el jugador; los mensajes de
#                múltiples líneas message-miss en el mismo hechizo sin una línea
#                power-cutoff intermedia se concatenarán

# Recuerda que lore, lore-color-base, lore-color-resist, lore-color-immune,
# message-save, message-vis, message-invis, message-miss se aplican a un rango
# específico de poderes de hechizo de monstruo. El límite inferior para los poderes
# de hechizo que afectará una línea dada es -infinito (si la línea en cuestión no
# tiene una línea power-cutoff antes de ella en el mismo hechizo) o uno más
# que el corte especificado en la última línea power-cutoff en el mismo hechizo
# antes de la línea en cuestión. El límite superior para los poderes de hechizo que
# afectará una línea dada es +infinito (si la línea en cuestión no tiene una línea
# power-cutoff después de ella en el mismo hechizo) o el corte especificado en la
# primera línea power-cutoff en el mismo hechizo después de la línea en cuestión.

# El texto entre llaves {} se reemplazará con la palabra apropiada cuando se
# muestren los mensajes proporcionados por message-vis, message-invis o message-miss;
# no se realizan reemplazos en el mensaje proporcionado por message-save.
# Las cadenas que se reemplazarán son:
# - {name} es el nombre del monstruo actuante
# - {pronoun} es su/su/su (pronombre posesivo)
# - {type} es el tipo de proyección que se está utilizando
# - {oftype} es como {type}, pero con "de" añadido - p.ej. "un látigo de fuego"
# - {target} es el objetivo del hechizo - jugador o (rara vez) otro monstruo
