# Archivo: store.txt

# Sintaxis para este archivo:

# store: código de característica                  - el código de característica es de list-terrain.h.
#                                        el nombre de la tienda es el nombre de esa característica
#                                        de terrain.txt. Generará un error
#                                        si la característica en terrain.txt no tiene
#                                        la bandera SHOP.
# owner: bolsa máxima : nombre          - debe especificarse al menos una vez, puede
#                                        aparecer múltiples veces
# turnover: rotación                    - cuántos objetos rota la tienda
# slots: mínimo : máximo                - número de espacios 'normales' para mantener abastecidos
# normal: tipo nombre : nombre del objeto - para la lista de abastecimiento normal
# always: tipo nombre : ?nombre del objeto - para objetos que siempre están en stock
# buy: tipo nombre                      - tipos base que la tienda comprará
# buy-flag: bandera : tipo nombre       - tipos a comprar si la bandera está presente
