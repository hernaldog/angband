# Archivo: class.txt


# Este archivo se utiliza para inicializar la información de las "clases de jugador" para Angband.

# No modifiques este archivo a menos que sepas exactamente lo que estás haciendo,
# a menos que quieras arriesgarte a posibles caídas del sistema y archivos guardados dañados.

# === Entendiendo class.txt ===

# Formato:
# name:número de clase:nombre de clase
# stats:str:int:sab:des:con
# skill-disarm-phys:base:incremento
# skill-disarm-magic:base:incremento
# skill-device:base:incremento
# skill-save:base:incremento
# skill-stealth:base:incremento
# skill-search:base:incremento
# skill-melee:base:incremento
# skill-shoot:base:incremento
# skill-throw:base:incremento
# skill-dig:base:incremento
# hitdie:incremento
# exp:porcentaje
# max-attacks:cantidad
# min-weight:peso en décimas de libra
# strength-multiplier:factor multiplicador
# title:título
# equip:tval:sval:mín:máx:opciones
# obj-flags:banderas de propiedad de objeto
# player-flags:banderas de propiedad de jugador
# magic:primer_hechizo:peso_hechizo:número_libros
# book:tval:calidad:nombre:hechizos:reino
# book-graphics:símbolo:color
# book-properties:coste:comunidad:min to max
# spell:nombre:nivel:maná:fallo:exp
# effect:efecto:subtipo (si es necesario):radio (si es necesario):parámetro (si es necesario)
# effect-yx:rango_y:rango_x
# dice:cadena de dados
# expr:expresión de dados
# effect-msg:mensaje
# desc: descripción


# 'name' indica el comienzo de una entrada. El número de serie debe
# aumentar para cada nueva clase.

# 'stats' es para los modificadores de estadísticas - fuerza, inteligencia, sabiduría,
# destreza, constitución.

# 'skill-<nombre de habilidad>' es para las habilidades - desarme físico y mágico,
# dispositivos mágicos, tiradas de salvación, sigilo, probabilidad de golpe (normal),
# probabilidad de golpe (arcos), probabilidad de golpe (lanzar), excavación. La entrada base
# es lo que se añade a las habilidades del personaje al nacer, los incrementos se añaden
# a la habilidad base cada diez niveles.

# 'hitdie' establece la contribución de la clase a los puntos de vida máximos ganados por
# nivel

# 'exp' establece la contribución aditiva de la clase, en porcentaje, a la penalización
# de puntos de experiencia. Las clases actuales no establecen esto y obtienen la
# penalización predeterminada de cero.

# 'max-attacks' establece el número máximo posible de golpes por ronda.

# 'min-weight' es el mínimo, en décimas de libra, impuesto al peso de un arma
# al calcular el número de golpes por ronda.

# 'strength-multiplier' es el multiplicador para la contribución de la fuerza al
# número de golpes por ronda; un valor mayor otorga más golpes.

# 'equip' es para el equipo inicial - tval del objeto, sval del objeto,
# cantidad mínima, cantidad máxima, nombres de las opciones de nacimiento separados por espacios
# o | (o ninguno si no hay reglas de exclusión) que excluirán el objeto si está activado
# (o, si el nombre de la opción está precedido por NOT-, excluirá el objeto si
# no está activado).

# 'obj-flags' es para las propiedades de objeto (de object_property.txt) que
# tiene la clase.

# 'player-flags' es para las propiedades de jugador (de player_property.txt) que
# tiene la clase.

# 'title' es para los títulos de clase.

# 'magic' es para la información mágica general - nivel del primer hechizo, peso que
# perjudica los hechizos, número de libros usados.

# 'book' define uno de estos libros - base de objeto, si es un libro de ciudad o de
# mazmorra, nombre, número de hechizos, reino del libro. Es necesario definir un libro
# para cada clase que lo use, ya que de lo contrario no se reconoce como uno de los libros
# de esa clase.

# 'book-graphics' es para el símbolo y el color como se usa en object.txt.
# Las líneas 'book-graphics:' se refieren a la línea de libro anterior, y no es necesario
# incluirlas si ya se ha definido un libro con el mismo nombre anteriormente.

# 'book-properties' es para las propiedades de objeto de un libro - coste, comunidad,
# y profundidades mínima y máxima de aparición.
# Las líneas 'book-properties:' se refieren a la línea de libro anterior, y no es necesario
# incluirlas si ya se ha definido un libro con el mismo nombre anteriormente.

# 'spell' define un hechizo individual - nombre, nivel, maná requerido,
# tasa de fallo, experiencia por el primer lanzamiento. Las líneas 'spell:' siempre se refieren a
# los hechizos en la línea 'book:' anterior. Las líneas siguientes se usan todas en
# referencia a la línea 'spell:' anterior.

# 'effect' define el efecto del hechizo (como se lista en src/list-effects.h),
# y opcionalmente parámetros para el subtipo de efecto, radio de efecto y
# un parámetro extra para varias cosas.

# 'effect-yx' establece el rango y (vertical) y el rango x (horizontal)
# alrededor del centro del efecto. Solo algunos efectos (a menudo detecciones) usan esos
# rangos.

# 'dice' proporciona un valor aleatorio para ser usado por un efecto (para daño,
# curación, etc.). Además de los campos de valor aleatorio normales descritos arriba,
# puede contener expresiones como $B, que se refieren a una línea 'expr' posterior.

# 'expr' proporciona una expresión para usar en los dados de efecto. Consiste en una
# letra de código (ej. B) para la expresión, una función base a usar (por ejemplo
# PLAYER_LEVEL), y una secuencia de operaciones a realizar sobre esa base.

# 'effect-msg' proporciona un mensaje que puede ser usado de la manera que el efecto
# necesite, típicamente para imprimir durante el efecto, o como mensaje de muerte.

# 'desc' es para la descripción. Se pueden usar tantas líneas desc: como sean necesarias
# para describir el hechizo. Nótese que las líneas necesitarán espacios al final
# o al principio de la siguiente línea para evitar que las palabras se junten.
